Generación de imagen por API

La interfaz no contiene claves privadas. Para generar imágenes, configurá un endpoint backend propio que autentique la solicitud y llame a OpenAI Images API.

Modo preparado: requiere un backend que acepte POST JSON { "prompt": "..." } y devuelva { "imageUrl": "https://..." }. No pegues una clave API de OpenAI aquí.
Los prompts se construyen en este navegador. No se guardan en un servidor por esta interfaz.
